# 🔢 Week 2: Processing Data, Variables & Error Handling

> Qaybtan waxay si qoto dheer ugu socotaa farsamaynta xogta, abuurista variables-ka, samaynta xisaabaadka, iyo ka hortagga khaladaadka (runtime errors) ee barnaamijyada C#[cite: 2].

---

## 📌 Chapter 2 Concepts & Topics

### 1️⃣ Variables & Data Types
* Abuurista iyo adeegsiga **primitive data types** sida `string`, `int`, `double`, iyo `decimal` 
* Fahamka xadka iyo hab-dhaqanka doorsoomayaasha xogta 

### 2️⃣ String Operations & Concatenation
* Sida qoraallada ama erayada la isugu xiro iyadoo la adeegsanayo astaanta **`+`** (String Concatenation) 
* Ku dhex-milanka xogta qoraalka iyo lambarada 

### 3️⃣ Input/Output & Parsing
* Akhrinta xogta ka imaanaysa **`TextBox`** controls 
* U beddelidda qoraalka lambaro iyadoo la adeegsanayo hababka:
  * `int.Parse()` 
  * `double.Parse()` 
  * `decimal.Parse()` 

### 4️⃣ Mathematical Operations & Casting
* Samaynta xisaabaadka aasaasiga ah iyo **Integer Division** 
* **Explicit Type Conversion (Casting)** si loogu beddelo noocyada xogta int u dhaxeeya.

### 5️⃣ Number Formatting (.ToString)
* Habaynta qaabka ay lambaradu u soo baxayaan iyadoo la adeegsanayo hababka sida `.ToString("n1")` ama qaabka lacagaha

### 6️⃣ Exception Handling (`try-catch`)
* Qabashada khaladaadka **runtime errors** si uusan barnaamijku u xirmanin (crash) marka user-ku galiyo xog aan sax ahaynv
