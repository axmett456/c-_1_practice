## 2. Course Objectives

By the end of this course, students should be able to:

1. Understand the fundamentals of C# programming.
2. Apply programming logic and problem-solving techniques.
3. Understand event-driven programming.
4. Develop graphical user interface (GUI) applications.
5. Work with methods, arrays, lists, and files.
6. Connect C# applications with databases.
7. Develop desktop applications.

## 4. Learning Outcomes

After completing this course, students should be able to:

1. Understand Windows and event-driven programming.
2. Develop GUI applications.
3. Apply programming logic when solving problems.
4. Use C# programming structures correctly.
5. Use methods to organize programs.
6. Work with arrays and lists.
7. Connect applications to databases using ADO.NET.
8. Develop small- to medium-sized Windows applications.

## 7. Course Project

Students will develop a desktop application at the end of the semester.

The project should demonstrate the following concepts:

- User Interface Design
- Variables and Data Types
- Decision Structures
- Loops
- Methods
- Arrays or Lists
- Database Connectivity
- ADO.NET
- Desktop Application Development
